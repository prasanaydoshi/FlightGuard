# Two-minute demo

1. Serve `web/` and open BOS → SEA on March 10, 2025. Explain these are constructed historical connections from actual BTS flight records.
2. Sort by shorter journey, then lower failure risk. Select an itinerary; inspect timezone-labeled dates and the same-inbound alternative.
3. Show model terms and vary the hypothetical layover. Explain this is a model-input sensitivity, not an available flight or causal forecast.
4. Save up to three itineraries. Reveal recorded outcomes and optionally export the shortlist. Outcome columns are omitted unless reveal is on.
5. Scroll to Evidence. Compare the full model with the stronger layover-only baseline, and show the extra journey time behind lower failure rates.
6. Open the model card and manifest, then show passing tests and reproducible evaluation. Do not call synthetic itinerary labels actual passenger outcomes or claim this is ready for live booking decisions.
